# 산재 알림 실시간 피드 — 백엔드 API 안내 ([137])

홈 **산재 알림** 카드가 아래 두 경로를 10분마다 호출한다. 화면은 응답 중 **학교 업무 관련 항목만** 다시 걸러서 보여 준다
(`src/lib/accidentRelevance.ts`). 경로가 없거나 실패하면 해당 출처만 조용히 빠지고 회사 산재는 그대로 나온다.

## 1. `GET /api/v1/accidents/news?limit=10` — 신규 (운영 백엔드 구현 필요)

산재 관련 뉴스 기사. 최신순.

```json
{
  "items": [
    {
      "source": "news",
      "title": "학교 급식실 조리실무사, 국솥 뜨거운 물에 화상",
      "summary": "기사 요약(선택, 140자 이내)",
      "url": "https://… 기사 원문 링크",
      "date": "2026-10-22T01:00:00Z",
      "publisher": "연합뉴스",
      "tags": [{ "label": "급식실", "kind": "sector" }, { "label": "화상", "kind": "type" }],
      "score": 16
    }
  ],
  "updated_at": "2026-10-22T01:05:00Z"
}
```

- `tags`·`score`는 선택. 없으면 화면이 제목·요약으로 직접 계산한다.
- **참고 구현:** `dev-backend.mjs`의 `fetchNews()`. 구글 뉴스 RSS 검색(키 불필요)을 아래 검색어로 조회한다.
  - 학교 급식실 산재 / 급식 조리실무사 사고 / 급식실 폐암 산재 / 학교 급식 노동자 화상 / 학교 시설관리 사고 / 학교 미화원 사고 / 교육청 중대재해 / 학교 종사자 산업재해
  - 최근 45일, 제목 기준 중복 제거, 관련성 필터, **서버 캐시 30분**(외부 과호출 방지).
- 네이버 뉴스 검색 API로 바꿀 경우 Client ID/Secret이 필요하다(응답 형식만 위와 같으면 화면 수정 불필요).

## 2. `GET /api/v1/accidents/kosha/cases?pageNo=1&numOfRows=50` — 기존 경로

KOSHA 국내재해사례(공공데이터포털). 화면이 50건을 받아 학교 업무 관련 사례만 남긴다(대부분 건설·제조라 0~몇 건).
응답 형식은 기존과 같다: `{ items:[{title, contents, business, boardno}], total, page, size }`.

## 관련성 규칙 (요약)

- 학교 업무 단어(급식실·조리·시설관리·미화·통학·교육청 등) **와** 사고 유형 단어(중대재해·화상·끼임·넘어짐·추락·폐질환·산재 등)가 함께 있을 것
- '학교'·'교육청'만 걸린 경우는 사망·중대재해처럼 강한 사고 단서가 있을 때만 인정
- 지역([138]): 전남 기사 우선, 다른 시·도(대전·경기·광주 등) 기사 제외, 지역 언급 없는 전국 기사는 포함
- 제외어: 학교폭력, 수능·입시, 수학여행, 학생 안전사고, 급식 메뉴·급식비 등
