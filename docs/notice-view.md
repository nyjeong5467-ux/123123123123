# 홈 공지사항 — 내용 보기 · 관리 권한 [172]

| 화면 | 내용 |
|---|---|
| 홈 › 공지사항 카드 | 제목 아래 본문 한 줄 미리보기. 행을 누르면 상세 창. 6건 넘으면 '전체 공지 보기' |
| 상세 창 | 필독/안내 · 제목 · 작성일 · 본문(작성한 줄바꿈 그대로) · 첨부파일 |

## 권한

- **공지 등록 · 필독 고정/해제 · 삭제**: 역할이 **본사 관리자(hq_admin)·경영진(executive)** 인 계정만 버튼이 보인다(`/auth/me` 의 role).
- 그 외(현장 점검자 등)는 보기만 가능 — 카드에 '공지 등록' 버튼 없음, 상세 창에는 [닫기]만.
- 행마다 있던 '해제'·'✕' 버튼은 카드에서 빼고 상세 창으로 옮김(실수 삭제 방지, 삭제 전 확인창).

## 백엔드 담당자 참고

- 화면에서 버튼을 숨기는 것만으로는 막을 수 없다. 실서버에서 `POST/PUT/DELETE /notices` 를 **hq_admin·executive 역할만 허용**(그 외 403)하도록 막아 주세요.
- 공지 저장 형식·API 변경 없음.
