# KOSHA 재해사례 — 학교·기관 직종 분류 [166]

산업재해 › 국내재해사례 › KOSHA 재해사례. 공단 '업종(건설업·제조업)' 대신 **학교·기관 직종**으로 사례를 모아 보여 준다.

| 대상 | 직종 |
|---|---|
| 학교 | 급식·조리 · 당직·경비 · 통학·운전 · 시설관리 · 미화 |
| 기관(교육지원청 등) | 당직·경비 · 통학·운전 · 시설관리 · 미화 · 사무·행정 · 도서관 · 수련·연수시설 |

- 조회: 직종마다 검색어(`JOBS[].q`)로 `GET /accidents/kosha/cases?keyword=` 를 나눠 부르고(검색어당 50건) 합친다 → 글번호 중복 제거 → 건설·제조 사례 제외(공단 업종 건설·제조·광업·조선, 제목·내용의 비계·굴착·거푸집·프레스·공장 등) → 직종 규칙(`JOBS[].re`)에 맞는 것만.
- 재해 유형(떨어짐·넘어짐·끼임·화상 등)은 보조 필터. 키워드를 넣으면 그 키워드로 조회 후 같은 규칙으로 거른다.
- 목록 첫 칸: 직종 배지 + 재해 유형 배지. 공단 업종은 상세 창에만.
- 맨 아래 '공단 전체 사례 보기(건설·제조 포함)' — 원래 공단 목록(서버 쪽 나눔).
- 규칙: `src/lib/accidentRelevance.ts` (`JOBS`, `jobOf`, `ACC_TYPES`). 화면: `src/pages/Accidents.tsx`.

## 백엔드 담당자 참고

- 새 API 없음. 화면이 검색어 수만큼(전체 직종 기준 약 15회) 공단 API를 부르므로, 실서버에서는 하루 1회 직종별로 모아 저장해 두고 한 번에 돌려주는 방식(예: `GET /accidents/kosha/cases?job=meal`)을 권장. 응답 형식만 같으면 화면 수정은 조회 부분만 바꾸면 된다.
