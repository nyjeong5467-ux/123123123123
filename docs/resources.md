# 자료실 — [164]

화면: 검색 카드(업무 선택·검색어 / 많이 찾는 자료 / 필독) → 자료실 메뉴(폴더 × 세부 항목) → 자료 목록.

| 폴더 | 기본 세부 항목 |
|---|---|
| 01 공통 | 회사 규정·서식, 근태·출장 서식, 개인정보 서약서, 공문·안내문 |
| 02 안전점검 | 공정별 점검표, 점검 기준 해설, 사진대지 작성 예시, 교육청 업로드 안내 |
| 03 위험성평가 | 평가표 양식, 유해위험요인 목록, 정기·수시 작성 예시 |
| 04 근골격계 | 증상조사표, 유해요인 조사표, 보고서 양식, 작성 매뉴얼 |
| 05 교육 | 교육 PPT, 교육 영상, 출석부·수료증 |
| 06 지원 | 현장 앱(APK) — 릴리스 서버(/release) 파일 자동 표시, 사용 매뉴얼·FAQ |

- 법령·지침, 재해 참고사례는 두지 않음(법령은 수시 개정, 재해 사례는 산업재해 탭).
- 파일 형식(HWP·HWPX·WORD·EXCEL·PDF·PPT 등)은 확장자로 자동 표시. 새 자료(N)는 최근 7일.
- [+ 자료 올리기]: 선택 폴더에 올림 — 세부 항목 선택 또는 새 세부 항목 추가, 설명, 필독 고정, 기존 자료의 새 버전(이전 파일은 '이전 버전'으로 접힘).

## 저장 (백엔드 수정 없음)

- 파일: 기존 `/resources` API 그대로(POST 시 category는 '양식'으로 보냄, 800KB 이하 원본 저장).
- 분류·부가정보: org 문서
  - `resource-meta` `{ [자료id]: { folder, sub, desc?, pinned?, file?, group?, downloads?, ts? } }` — group 이 같으면 같은 자료의 버전들(최신본만 목록), downloads = 받은 수
  - `resource-folders` `{ [폴더key]: 추가한 세부 항목[] }`
- 분류 정보가 없는 기존 자료는 제목으로 폴더를 추정해 '미분류' 세부 항목에 표시.

## 백엔드 담당자 참고

- 나중에 `/resources` 에 folder·sub·desc·pinned·group·downloads 칸을 추가하면 위 org 문서를 대체할 수 있음(화면은 `src/pages/Resources.tsx` 의 meta 읽기·쓰기만 교체).
- 800KB 초과 파일도 원본 저장이 필요하면 파일 업로드(멀티파트) 경로가 필요.
